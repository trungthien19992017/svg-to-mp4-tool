# SVG để import thử

Mở http://127.0.0.1:5188/whiteboard sau khi chạy `start.cmd` hoặc `start.ps1`, rồi kéo một trong ba file SVG vào vùng nhập. Story Studio mới ở trang gốc nhận [lost-star.zip](lost-star.zip), với source tại [lost-star/](lost-star/).

- **01-ngoi-nha-mau.svg:** minh họa màu, đường cong, transform và chữ tiếng Việt. Chọn Nét trước, màu sau; dọc 9:16; 10 giây.
- **02-duong-cong-transform.svg:** kiểm tra arc, Bézier, subpath rời, transform và gradient. Chọn Nét trước, màu sau; ngang 16:9; 5 giây.
- **03-doodle-anh-nen.svg:** ảnh PNG nhúng và nét trắng vector riêng. Chọn Doodle trên ảnh nền; dọc 9:16; 5 giây. Nền có sẵn từ frame đầu, chỉ các nét trong group doodles được vẽ dần.

Các file hoạt động độc lập, không cần link ảnh bên ngoài. Giữ hình cuối 1 giây, bấm Tạo bản xem trước trước khi Xuất MP4. Hướng dẫn đầy đủ: [Chạy source](../docs/run-source.md).
