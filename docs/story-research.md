No stars or recency rankings are used as a quality guarantee. For nonselected repositories, URL/README review is not a source audit. Before reusing their code, pin a commit, inspect the exact algorithm/tests and complete asset/dependency license checks.

GSAP vendor script preserves original headers and copies a package license if provided; otherwise it records the declared license URL in NOTICE.gsap.txt. No CDN is used at runtime. Monaco is not added in this pass: the working code editor uses a textarea to avoid a large extra worker/AMD/CSP surface while runtime isolation is being validated. Monaco remains an optional UI enhancement, not a simulated component.
