# Robot pose, motion & interaction library

Open `preview.html` directly. It works from `file://` and displays only approved artwork cropped from the supplied sheets.

- `pose-catalog.json` — 34 static full-character and gesture keys.
- `motion-library.json` — 10 ordered motion key sets; timing remains unspecified and status remains Partial.
- `interaction-library.json` — four couple actions with four approved states each.
- `artwork/` — direct crops plus untouched source references.
- `source-rig/robot-rig-pack/` — supplied cutout SVG rigs, pivots and anchors.
- `QA-report.md` — validation evidence and unresolved timing input.

No intermediate pose, cadence, 3D turn or limb scaling is invented.
